# insight_demo_v2 数据快照

这是由 `insight_demo_v1` 底座发布的第二幕共享合成快照，供定向洞察和自动圈客共同绑定读取。客户全部为虚构的当前模拟代理人个险客户；数据不代表真实客户、行业统计、产品适配或经营结果。原 v1 身份与文件指纹保存在 `versions/1.0-manifest.json`，活跃文件不得再以 v1 版本或旧指纹使用。

## 快照口径

- dataset_id/version：`insight_demo_v2` / `2.0`
- synthetic：`true`
- analysis_as_of：`2026-09-22T00:00:00+08:00`
- 主窗口：左闭右开 `[2026-06-24T00:00:00+08:00, 2026-09-22T00:00:00+08:00)`
- channel_id：`individual`
- owner_actor_id：`AGENT_DEMO_001`
- family_stage：50 位均为 `null`，表示未采集，不表示没有家庭责任

## 文件

- `customers.jsonl`：50 位客户基础资料。
- `behaviors.jsonl`：117 条行为事件，含 107 条主窗口事件和 10 条历史事件。
- `topics.json`：5 个中性主题定义。
- `materials.json`：每个主题两篇虚构文章和一场虚构活动，共 15 条素材元数据。
- `data/product/product_catalog.json`：仅索引两份用户提供 Markdown 原文及其 SHA-256。
- `manifest.json`：活跃快照元数据和文件指纹，不包含自身指纹。
- `versions/1.0-manifest.json`：原版身份、数量和指纹的只读追溯清单。

## 语义覆盖

快照包含明确自身需求、一般知识咨询、替他人询问、同主题需求后撤回、无关主题后续否定，以及浏览、活动、跨主题、历史和无行为样本。运行时只消费原始档案和事件；独立人工评测标注位于 `data/evaluation/`，不得由模型、主 Agent 或业务 Tool 读取。

## 生成与验证

运行 `.\.venv\Scripts\python.exe scripts/validate_insight_mock_data.py`。校验覆盖引用、来源范围、左闭右开窗口、实际统计、指纹和数据变体。离线校验通过只说明数据内部一致。

## 使用限制

本快照没有预制 Opportunity、推荐名单、客户评分、成交概率、NBEV 预测、联系方式或产品适配标签。浏览、活动和年龄不能单独升级为需求结论。历史记录稀疏；“记录中未发现反馈”不表示现实中不存在反馈。模型对原话的解读必须标记为推断，并由独立语义评测验证。
