# insight_demo_v1 数据快照

这是按 `doc/design/2026-09-22-insight-mock-data-design.md` 生成的可复现合成快照，供后续定向洞察开发读取。客户全部为虚构的当前模拟代理人个险客户；数据不代表真实客户、行业统计、产品适配或经营结果。

## 快照口径

- dataset_id/version：`insight_demo_v1` / `1.0`
- synthetic：`true`
- analysis_as_of：`2026-09-22T00:00:00+08:00`
- 主窗口：左闭右开 `[2026-06-24T00:00:00+08:00, 2026-09-22T00:00:00+08:00)`
- channel_id：`individual`
- owner_actor_id：`AGENT_DEMO_001`
- family_stage：50 位均为 `null`，表示未采集，不表示没有家庭责任

## 文件

- `customers.jsonl`：50 位客户基础资料。
- `behaviors.jsonl`：115 条行为事件，含 105 条主窗口事件和 10 条历史事件。
- `topics.json`：5 个中性主题定义。
- `materials.json`：每个主题两篇虚构文章和一场虚构活动，共 15 条素材元数据。
- `data/product/product_catalog.json`：仅索引 `data/product/` 下两份用户提供 Markdown 原文及其 SHA-256，不重写条款。
- `manifest.json`：快照元数据和数据文件指纹，不包含自身指纹。
- `scripts/validate_insight_mock_data.py`：仅依赖 Python 标准库的结构、配额、时间、引用、统计和独立反例校验。

## 实际统计

以下数字由校验脚本从当前文件计算，不是预填的业务返回值：

| 口径 | 实际值 |
| --- | ---: |
| 全部客户 | 50 |
| 主窗口有行为的独立客户 | 40 |
| 仅历史有行为客户 | 5 |
| 所有时间无已记录行为客户 | 5 |
| 主窗口 / 历史事件 | 105 / 10 |
| 主窗口主动咨询客户 | 20 |
| 主窗口 explicit_interest 客户 | 15 |
| 主窗口 not_now / already_arranged 客户 | 3 / 2 |
| 主窗口跨主题客户 | 4 |

事件类型总数为：浏览 65、活动参与 10、咨询 25、回访表达 15；主窗口内为 60、10、20、15。主窗口主题独立客户数为：退休收入安排 13、家庭长期保障 10、资金使用安排 8、分红与不确定性 7、医疗与健康保障 6。不同主题的客户数存在交叉，不能相加作为总人数。

## 生成与验证

数据按设计中的年龄置换、客户行为组、主题例外和相对快照日期确定性生成；未使用网络、在线 LLM 或新增依赖。运行：

`.\.venv\Scripts\python.exe scripts/validate_insight_mock_data.py`

校验还在内存副本中验证：重复来源、未知客户、窗口起止边界、移除客户行为、移除明确兴趣表达，以及同一客户同主题浏览的事件数/独立客户数口径。

## 使用限制

本快照没有预制 Opportunity、推荐名单、客户评分、成交概率、NBEV 预测、联系方式或产品适配标签。主题和行为只描述内容及人工编码的客户表达；explicit_interest 不等于购买意愿、适配结论或触达授权。浏览、活动和年龄不能单独升级为需求结论。历史记录稀疏，不支持同比、环比或需求增长结论。通过离线校验只说明文件内部一致，不证明真实模型洞察质量、条款解释或完整 Demo 已实现。
